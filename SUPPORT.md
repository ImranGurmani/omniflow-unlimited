# Support

## Getting help

- **Issues & questions:** open an issue on the
  [GitHub repository](https://github.com/ImranGurmani/omniflow-unlimited/issues).
- **Public support email:** _to be added by the owner before the public release._

When reporting a problem, include:

1. OmniFlow version (shown in the app / installer name).
2. Windows version (10/11) and whether WebView2 and Chrome are installed.
3. The exact error message or a screenshot.
4. The steps that led to the problem.

**Do not** post license keys, account passwords, or browser session data publicly.

## Common issues

| Symptom | What to check |
| --- | --- |
| SmartScreen warning on install | Expected (unsigned). Verify the SHA-256 checksum and use only official Release assets. |
| App won't start | Install the WebView2 Evergreen Runtime; confirm Windows 10/11 x64. |
| Activation fails | Check internet access and that the OMNI2 key is valid and not revoked. |
| Generation unavailable | Confirm the license is active and you're signed in to your own Flow/Muse accounts in Chrome. |

## Licensing

License keys are issued by the OmniFlow team. If you need a key, a renewal, or a device
transfer, contact support through the channels above. Never share your key publicly.
